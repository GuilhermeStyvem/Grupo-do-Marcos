🩸 Sistema de Incentivo à Doação de Sangue | Grupo-1155
Uma plataforma web desenvolvida para simplificar o processo de doação de sangue, conectar doadores a postos de coleta próximos e desmistificar dúvidas sobre o tema.

📌 Sobre o Projeto
Muitas pessoas deixam de doar sangue por falta de orientação, dúvidas sobre os requisitos exigidos ou simplesmente por não saberem onde fica o posto de coleta mais próximo.

Este projeto visa resolver esses gargalos criando uma solução centralizada, acessível e intuitiva para orientar e incentivar potenciais doadores.

🎯 Principais Objetivos e Funcionalidades
Localizador de Postos: Identificação do ponto de doação / hemocentro mais próximo com base na localidade do usuário.

Guia de Compatibilidade Sanguínea: Informações claras e visuais sobre os tipos sanguíneos e quem pode doar para quem.

Central de Informações: Tira-dúvidas completo sobre pré-requisitos, impedimentos temporários/definitivos e orientações pós-doação.

Agilidade no Acesso: Interface simples voltada para engajar e conscientizar a comunidade.

🛠️ Tecnologias Utilizadas
Front-end
HTML5 & CSS3: Estrutura e estilização visual das páginas.

JavaScript: Lógica de navegação e dinamismo na interface.

React: Construção de componentes reutilizáveis e reativos para a aplicação web.

Back-end
Node.js: Ambiente de execução para criação da API e gerenciamento de rotas/servidor.

Python: Scripts de processamento de dados, automações ou integração de dados específicos.

Infraestrutura & Ferramentas
Ngrok: Utilizado para expor o servidor local à internet, facilitando testes remotos e demonstrações da aplicação.
